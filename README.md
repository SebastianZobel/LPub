# O2 Tower München – Website V2

Redesign als digitales Bauheft.

## GitHub Pages
1. Repository anlegen.
2. Inhalt dieses Ordners ins Repository-Root kopieren.
3. GitHub → Settings → Pages.
4. `Deploy from a branch`, Branch `main`, Ordner `/ (root)`.
5. Speichern.

Die Website benötigt keine externen Bibliotheken oder CDNs.
